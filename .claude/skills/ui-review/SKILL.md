# 2-2 · B급 시안 컨펌  (10/31 작성 예정)

이 스킬은 아직 완성되지 않았다. 10월 31일 제출 범위다.

호출되면 먼저 사용자에게 알린다.

> "2-2 컨펌 스킬은 10월 31일에 작성할 예정입니다. 지금은 `docs/quality-bar.md` 체크리스트를 수동으로 적용하는 것까지만 됩니다. 그렇게 진행할까요?"

## 지금 할 수 있는 것

사용자가 동의하면 정해진 범위 안에서만 진행한다.

1. `04-draft-log.md`에서 시안 정보를 읽는다
2. `docs/quality-bar.md`의 A부터 H까지 기계적으로 적용한다. 기준을 해석하거나 완화하지 않는다
3. 결과를 `05-review-log.md`의 기록 표 형식으로 적는다
4. 불합격 항목은 `docs/quality-bar.md`의 불합격 처리 표를 보고 어느 단계로 돌아가야 하는지 말한다

## 하지 않는 것

- 자동 재생성. 할지 말지가 10/31에 정할 항목이다
- 합격/불합격 기준을 임의로 만드는 것
- `05-review-log.md`의 `10/31까지 결정할 것` 칸을 추측으로 채우는 것

## 10/31까지 정할 것

`docs/02-stage-build.md`의 2-2 항목이랑 `templates/05-review-log.md`에 목록이 있다.

- 불합격이면 자동으로 다시 만들 건지, 지적만 하고 사람이 고칠 건지
- 검수 단위를 화면으로 볼 건지 컴포넌트로 볼 건지
- 합격선을 필수 항목 전부 통과로 할 건지, 가중치 점수제로 할 건지
- 3-1 검수 단계랑 역할 분담

## 바뀌지 않는 원리

뭘 왜 고쳤는지가 남아야 한다. 지금까지는 기준 없이 각자 눈대중이었고, 판단 근거가 안 남아서 누가 만들었느냐에 따라 결과가 달랐다. 그 아래쪽을 막아두는 게 이 단계다.

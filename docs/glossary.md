# 용어집

프로세스 문서랑 스킬 결과물에서 같은 뜻으로 씁니다.

| 용어 | 뜻 | 헷갈리기 쉬운 것 |
|---|---|---|
| **A급 시안** | 고객 제안의 메인 안. 디자이너가 직접 제작 | 등급이 아니라 역할 구분입니다 |
| **B급 시안** | 비교용 대안. AI가 만들고 사람이 고르고 손봄 | A급을 대충 만든 게 아닙니다 |
| **정석 / 변주 / 파격** | 스타일과 레이아웃이 얼마나 대담한지 세 단계 | A·B·C로 부르지 않습니다. A급/B급이랑 헷갈려요 |
| **동종 / 이종** | 레퍼런스 출처가 같은 업계인지 다른 업계인지 | |
| **1-4 방향 확정** | 구조랑 스타일을 정하는 지점. 사람이 함 | 회의가 아니라 파일에 적는 행위입니다 |
| **토큰** | 컬러, 타이포, 간격 같은 걸 이름 붙여 정해둔 값 | 값만이 아니라 이름이 붙어야 토큰입니다 |
| **원시값 / 의미값** | `neutral-700` / `text-primary` | 화면에서는 의미값만 씁니다 |
| **variant** | 한 컴포넌트가 갖는 속성 조합 | 컴포넌트를 복제하는 것과 다릅니다 |
| **상태값** | hover, focus, disabled, empty, error, loading | 빠뜨리면 개발에서 임의로 만듭니다 |
| **존 (zone)** | 화면을 위에서 아래로 나눈 구역 | 섹션이랑 같은 뜻으로 씁니다 |
| **화면 ID** | 화면 목록에서 붙인 고유 식별자 | 시안 프레임 이름의 첫 조각 |
| **상태 변형** | 한 화면이 조건에 따라 갖는 다른 모습 | 화면 수를 1.3~1.6배로 만드는 요인 |
| **품질 기준** | B급 시안 체크리스트 | 통과했다고 합격은 아닙니다 |
| **결정 기록** | 뭘 골랐고, 왜, 뭘 버렸는지 | 템플릿 필수 항목 |
| **플레이스홀더** | 실제 에셋 자리에 놓는 색상 사각형 | 규격 표기가 꼭 붙습니다 |
| **인계 격차** | Figma 자동 조작 한계로 의도랑 달라지는 부분 | 폰트, 사진, 그라데이션. 매번 고지 |
| **AI 레이어** | 기존 프로세스 밑에 까는 AI 활용 층 | 프로세스를 대체하는 게 아닙니다 |

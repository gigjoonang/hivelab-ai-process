# 에셋 프롬프트

2-3 단계에서 씁니다. 프롬프트를 잘 쓰는 것보다 프로젝트 토큰을 프롬프트에 넣는 게 훨씬 중요해요. 예쁜 이미지가 필요한 게 아니라 이 시안에 맞는 이미지가 필요한 거니까요.

---

## 프롬프트 여섯 단

이 순서로 쓰면 다시 만들 때 비슷하게 나옵니다. 앞에 올수록 결과에 크게 반영됩니다.

```
[1 피사체]   뭐가 있는가. 명사 중심으로, 형용사는 최소로
[2 구도]     시점, 배치, 여백. 텍스트 올라갈 자리를 비워둘 건지
[3 스타일]   사진 / 일러스트 / 3D / 추상. 구체적인 장르명으로
[4 컬러]     프로젝트 토큰 값을 그대로 넣습니다
[5 조명·질감] 광원 방향, 대비, 노이즈나 그레인
[6 규격]     비율, 해상도
```

### 히어로 배경 그래픽

```
abstract flowing gradient mesh, no objects, large empty space on the left half,
minimal digital art, primary color #1A4FD6 and accent #FF6B2C on deep neutral #0E1116,
soft diffused light from top right, subtle film grain,
16:9 wide composition
```

왼쪽 절반을 비운 건 헤드라인이 거기 오기 때문입니다. 텍스트 올라갈 자리를 먼저 지정하세요. 안 그러면 매번 다시 만들게 됩니다.

컬러는 `03-design-tokens.md`의 실제 값을 씁니다. "파란색"이라고 쓰면 시안이랑 다른 파란색이 나와요.

### 섹션 일러스트

```
simple line illustration of [주제], single continuous stroke style,
2px uniform line weight, no fill, on transparent background,
line color #1A4FD6 only,
centered composition with generous margin, square 1:1
```

선 굵기를 숫자로 지정합니다. 아이콘 세트랑 굵기가 달라지면 한 화면에서 바로 티가 납니다.

### 반복 배경 패턴

```
seamless tileable geometric pattern, thin lines forming irregular grid,
very low contrast, #0E1116 background with #1A4FD6 lines at 12% opacity,
flat, no gradient, no shadow, square tile
```

`seamless tileable`을 빼면 이어붙일 때 경계가 보입니다.

## AI로 만들지 않는 것

| 대상 | 왜 | 대신 |
|---|---|---|
| 사람 얼굴 | 고객사가 알아봅니다. 표정이랑 손가락이 어긋나요 | 스톡이나 고객사 제공 |
| 실제 제품 | 형태가 미묘하게 틀립니다 | 고객사 제공. 필수 |
| 로고 | 브랜드 자산입니다 | 고객사 제공 또는 직접 제작 |
| 텍스트 들어간 이미지 | 글자가 깨집니다. 한글은 특히 | 이미지 위에 실제 텍스트 레이어 |
| 정확한 다이어그램·차트 | 구조가 안 맞습니다 | 직접 제작 |
| 특정 장소 | 없는 건물이 나옵니다 | 스톡이나 촬영 |

판단 기준은 [02-stage-build.md](02-stage-build.md)의 2-3 확보 경로 표를 보세요.

## 시안용 임시 대체물

2-1 시안 단계에서 최종 에셋이 아직 없을 때, 플레이스홀더 대신 분위기만 맞는 걸 만들어 쓰면 방향 판단이 훨씬 정확해집니다. 다만:

- 파일명에 `_TEMP`를 붙입니다. `HOME_hero-bg_TEMP_2880x1620.webp`
- `06-assets.md`에 `대체물 — 최종 교체 필요`로 적어둡니다
- 고객사 전달 전에 꼭 교체합니다. 교체 확인은 3단계 검수 항목이에요

## 규격

`03-design-tokens.md`나 기획서에 다른 값이 없으면 이걸 씁니다.

### 해상도
| 용도 | 1배 | 제작 규격 |
|---|---|---|
| 풀블리드 히어로 배경 | 1920×1080 | 2880×1620 |
| 콘텐츠 폭 이미지 | 1200×675 | 2400×1350 |
| 카드 썸네일 | 400×300 | 800×600 |
| 아바타 | 80×80 | 160×160 |
| 아이콘 | — | SVG (24×24 기준 그리드) |

### 포맷
```
사진          WebP  (JPEG는 대체 포맷으로만)
그래픽·아이콘  SVG
투명 필요     PNG-24
애니메이션     Lottie(JSON) 또는 WebM. GIF는 안 씁니다
```

### 용량
```
히어로 이미지    300KB
일반 이미지      150KB
썸네일           60KB
아이콘 SVG       10KB
```

넘으면 디자인 문제가 아니라 성능 문제가 됩니다. 개발 인계할 때 반드시 지적받아요.

### 메타 이미지
```
OG 이미지   1200×630   텍스트는 중앙 안전영역 안에
파비콘      SVG + 32×32 PNG + 180×180 (apple-touch-icon)
```

### 비율
```
16:9   히어로, 동영상 썸네일
4:3    일반 콘텐츠 이미지
1:1    아바타, 아이콘, SNS
3:2    사진 갤러리
```

한 화면에서는 두 종류 이내로 씁니다. 세 종류 넘게 섞이면 정렬이 무너져요.

## 대체 텍스트

모든 이미지에 씁니다. 접근성 요구가 있으면 필수고, 없어도 SEO에 쓰입니다.

```
장식용 이미지     alt=""  빈 값입니다. 생략이 아니라 빈 값
정보 전달 이미지   이미지가 없을 때 대신 읽힐 문장
링크 안 이미지     이미지 설명 말고 링크가 어디로 가는지
```

"이미지", "사진", `img_hero_01`, 파일명 그대로는 쓰지 마세요.

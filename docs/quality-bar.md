# 품질 기준 — B급 시안 체크리스트

여기 다 통과했다고 좋은 시안은 아닙니다. 하나라도 못 넘으면 못 나가는 선일 뿐이에요.

지금까지는 기준이 없어서 각자 눈대중으로 봤습니다. 그러다 보니 누가 만들었느냐에 따라 결과가 달랐고요. 이 목록은 그 아래쪽을 막아두려고 만들었습니다.

`/ui-draft` 끝낼 때 스스로 점검하고, `/ui-review`가 다시 기계적으로 검사합니다.

---

## A. 토큰 준수

불합격이 제일 많이 나오는 구간입니다.

- [ ] `03-design-tokens.md`에 없는 색이 하나도 없다. 화면에서 색을 뽑아 표랑 대조합니다
- [ ] 토큰에 없는 폰트 크기가 없다. 17px, 23px 같은 게 끼어 있지 않다
- [ ] 간격이 전부 간격 스케일 값이다. 4/8 배수를 벗어난 게 없다
- [ ] 반경이랑 그림자가 정의된 단계 안에 있다
- [ ] 그리드 칼럼, 거터, 최대폭이 `01-ui-structure.md` 값이랑 같다

토큰이 새면 시안이 망가지는 게 아니라 디벨롭이 망가집니다. 전 화면에 퍼진 다음에 발견되거든요.

## B. 대비와 접근성

- [ ] 본문 텍스트 대비 4.5:1 이상 — 실측
- [ ] 큰 텍스트(18.66px+ Bold 또는 24px+) 3:1 이상
- [ ] 버튼, 입력필드 경계, 아이콘 3:1 이상
- [ ] 플레이스홀더 텍스트가 본문 대비 기준을 넘는다
- [ ] 이미지 위 텍스트에 오버레이나 그림자 처리가 있다
- [ ] 색만으로 정보를 구분하는 곳이 없다. 아이콘이나 텍스트, 형태를 같이 쓴다
- [ ] 터치 타겟 44×44px 이상 (모바일)

## C. 상태값

두 번째로 많이 나오는 구간입니다.

- [ ] 버튼 — default / hover / pressed / disabled 네 종
- [ ] 입력 — default / focus / error / disabled 네 종에 에러 메시지 자리까지
- [ ] 링크 — default / hover / visited
- [ ] 목록 화면에 빈 상태 디자인이 있다
- [ ] 로딩 상태 처리 방식이 정해져 있다. 스켈레톤인지 스피너인지 안 쓰는지
- [ ] 선택·활성 상태. 탭, 내비, 체크박스

## D. 콘텐츠가 현실적인가

- [ ] `Lorem ipsum`이 없다. 국문 카피는 국문으로 들어가 있다
- [ ] 제일 긴 경우를 넣어봤다. 제목 두 줄, 메뉴명 최장, 가격 여덟 자리, 이름 긴 경우
- [ ] 제일 짧은 경우도 넣어봤다. 항목 하나, 텍스트 한 줄
- [ ] 목록 항목 수가 실제 예상 범위다. 카드 세 장짜리 목록으로 판단하지 않았다
- [ ] 이미지 자리에 실제 비율이랑 규격이 표기돼 있다

## E. 구조가 맞나

- [ ] `01-ui-structure.md`의 확정 레이아웃이랑 존 순서가 같다
- [ ] 화면 목록에 있는 화면이고 ID가 붙어 있다
- [ ] 내비게이션 항목이 IA 트리랑 일치한다
- [ ] 반응형. 데스크톱 말고 최소 하나 브레이크포인트가 있다

## F. 편집이 되나

Figma 시안만 해당합니다.

- [ ] 반복 요소가 전부 컴포넌트 인스턴스다. 복사 붙여넣기한 그룹이 없다
- [ ] 모든 프레임에 오토레이아웃이 걸려 있다
- [ ] 직접 입력한 색상이 없다. 전부 스타일이나 변수 연결
- [ ] 텍스트가 텍스트 스타일에 연결돼 있다
- [ ] `Rectangle 42`, `Frame 128` 같은 이름이 없다
- [ ] 프레임 이름이 `화면ID_화면명_등급_방향` 형식이다

## G. 스타일 방향이 맞나

- [ ] `02-design-style.md`의 확정 방향이랑 일치한다
- [ ] 세 방향을 만들었으면 서로 확실히 다르다. 색만 다른 건 같은 안이다
- [ ] 2-1-a에서 정한 디자인 규칙 세 개를 안 어겼다

## H. 전달할 때 같이 말할 것

- [ ] B급 시안이라고 밝혔다
- [ ] 폰트가 의도랑 다를 수 있다고 말했다
- [ ] 사진이 색상 플레이스홀더라고 말했다
- [ ] 어느 구조안에 어느 스타일 방향 조합인지 밝혔다

## 되돌리는 방법

Claude에게 말하면 됩니다.

```
가이드 사이트 v4_2026-09-16 버전으로 되돌려줘
```

## 새로 백업하는 방법

디자인을 바꾸기 **전에** 말하세요.

```
지금 가이드 사이트 백업해두고 시작하자
```

## 직접 하고 싶으면

```bash
# 백업
cp guide-site/index.html guide-site/versions/v6_$(date +%Y-%m-%d).html

# 되돌리기
cp guide-site/versions/v4_2026-09-16.html guide-site/index.html
```

되돌린 뒤에는 Claude에게 다시 발행해달라고 해야 실제 주소에 반영됩니다. 파일만 바꾸면 로컬만 바뀝니다.

## 파일 형식

`.html` 그대로 둡니다. PDF나 PNG로 뽑으면 볼 수는 있어도 되돌릴 수가 없습니다.
CSS와 JS가 전부 파일 안에 들어 있어서 파일 하나로 완결됩니다.

## 다크 버전의 배경 사진

`dark.html` 맨 위 `--hero-photo` 값 한 줄만 바꾸면 그라디언트 대신 사진이 깔립니다.
피그마 01 프레임의 인물 사진을 내보낸 뒤 base64로 넣으면 됩니다. 자세한 건 그 파일 상단 주석에 있습니다.
